## Описание
Планировщик хранит задачи; каждая из них содержит дату дедлайна и заголовок с комментарием. Задачи могут повторяться по заданному правилу: например, ежегодно, через какое-то количество дней, в определённые дни месяца или недели. Если отметить такую задачу как выполненную, она переносится на следующую дату в соответствии с правилом. Обычные задачи при выполнении будут просто удаляться.\
API содержит следующие операции:
* Добавить задачу;
* Получить список задач;
* Удалить задачу;
* Получить параметры задачи;
* Изменить параметры задачи;
* Отметить задачу как выполненную.

## Список выполненных заданий со звёздочкой
Все задания со звездочкой выполнены:
* Реализована возможность определять порт при запуске сервера через переменную окружения ```TODO_PORT```;
* Реализована возможность определять путь к файлу базы данных через переменную окружения ```TODO_DBFILE```;
* Реализованы правила повторения: ```w <через запятую от 1 до 7>``` и ```m <через запятую от 1 до 31, -1, -2> [через запятую от 1 до 12]```;
* Реализована возможность поиска задач по заголовку, комментарию и конкретной дате;
* Реализована аутентификация;
* Докер-образ описан.
## Инструкция по запуску кода локально
Для запуска проекта локально достаточно в корне проекта выполнить команду: ```go run main.go```.\
Также можно предварительно указать следующие переменные окружения:
```
export TODO_PORT=8080
export TODO_PASSWORD=12345
export TODO_DBFILE=./data/scheduler.db
```
## Инструкция по запуску тестов
Для запуска тестов необходимо предварительно запустить проект локально.\
Далее выполнить команду: ```go test ./tests```.\
Если были добавлены переменные окружения, их также следует добавить в терминале, в котором будет запускаться тестирование:
```
export TODO_PORT=8080
export TODO_DBFILE=../data/scheduler.db
```
Файл ```tests/settings.go``` уже заполнен корректно для запуска без изспользования переменных окружения:
```
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = true

```
## Инструкция по сборке и запуску проекта через докер
Необходимо собрать образ проекта:\
```docker build -t final-project .```\
Далее запустить контейнер с указанием внутреннего и внешнего порта, а также монтируемых директорий:\
```docker run -p 8080:8080 -v $(pwd)/data:/app/data final-project```
